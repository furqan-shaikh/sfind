### Dev Setup
#### Add as a submodule
 - From your repo root, run `git submodule add https://github.com/facebookresearch/perception_models.git sfind/perception_models`
 - This will clone `perception_models` into `sfind/perception_models` inside your repo.

#### Initialize / update submodules (for new clones)
 - Run `git submodule update --init --recursive`
